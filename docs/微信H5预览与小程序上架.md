# 微信 H5 预览与后续小程序上架

更新日期：2026-10-16。当前源码为 H5 网页游戏，支持公网 H5 与离线使用，不代表已上架微信小程序。

微信分享入口：[打开游戏](https://word-pop-adventure-jwj.netlify.app/)。正式站点由用户 Netlify Free 团队管理，关闭登录限制。GitHub Pages 保留作备用。下面的 Pages 首次设置步骤仅在迁移到新仓库时需要重做。

## 当前离线使用

无需注册云账号。用电脑 Edge / Chrome 打开交付的 `单词消消乐-离线版.html`；也可从源码执行 `npm ci`、`npm run build:preview` 生成 `dist-preview/word-pop-offline.html`。
单文件内含素材、喝彩音效、文档解析及图片识别组件。Word 请使用 .docx，Excel 请使用 .xlsx / .xls，亦支持 PNG / JPG / TXT。
图片识别完成后检查并修正英文、中文再保存，导入文件不上传到服务器。系统单词朗读是否可离线使用取决于已安装的语音。
学习进度和榜单只保存在本机；离线文件不能成为可点击的公网邀请链接。需要发给好友时发送整个 HTML 文件，让对方在电脑浏览器打开。

## 免费 H5 发布

1. 用仓库所有者账号打开 [Pages 设置](https://github.com/jwj-dot12/Game/settings/pages)。
2. 在 Build and deployment 中，将 Source 设为 **GitHub Actions**。
3. 打开 [Publish H5 preview](https://github.com/jwj-dot12/Game/actions/workflows/preview.yml)，点击 Run workflow，选择 main。
4. 等待 build、deploy 变绿，打开部署显示的网址。预期为 `https://jwj-dot12.github.io/Game/`，以成功结果为准。
5. 把公网链接发送到自己的微信，在真机打开验证。不要把电脑的 `127.0.0.1` 地址发送给别人。

GitHub Free 的公开仓库可使用 Pages，但只能托管静态页面，不能运行本项目 Node.js + SQLite 后端。
预览版明确显示“本机预览榜”，只读当前浏览器的真实成绩，不伪造联网排行。
参见 [GitHub Pages 官方工作流说明](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 邀请好友

点击“邀请好友挑战”，选择“分享至微信”、复制链接，或生成二维码海报。
在微信内点击“分享至微信”，按提示点右上角 `···` → “发送给朋友”，选择聊天发送。
在其他支持系统分享的浏览器中，会打开系统分享面板；已安装微信且系统提供微信目标时，可选择微信。
不支持系统分享的浏览器会复制挑战链接，随后在微信聊天粘贴发送；用户取消系统分享时不会自动复制。
浏览器拒绝自动复制时，按弹窗提示长按已选中的链接复制。
微信内可尝试长按海报保存/识别，也可点击保存海报。二维码对应当前单元或综合挑战。
海报在本地生成，不调用外部图片服务；自定义词表不会被分享出去。

尚未配置公众号 JS-SDK 签名服务，网页不会直接打开指定微信聊天或自动发送，也不保证自定义右上角分享卡片的标题和缩略图。需要准确分享指定单元时，可使用弹窗中的挑战链接或二维码。

## 玩家资料与制作信息

默认昵称为 Holly LU、地域为上海·嘉定、班级名称为太阳花中队；设置中可手动修改地域，不读取设备定位。排行榜昵称后显示本次成绩的地域。
旧版默认昵称会更新，自定义昵称和学习进度保留。完整后端会自动增加地域字段，原有成绩默认显示上海，不删除旧成绩。
右上角头像昵称打开“我的”：查看积分，修改昵称、头像、地域和班级。头像可选择卡通小伙伴或上传最大 5 MB 的 JPG / PNG / WebP，在本机裁成方形并压缩，不上传到服务器。
通关最终得分累计为积分。旧版仅以浏览器中仍保留的历史成绩初始化一次，不补造已清理的历史分数。昵称最多 6 个汉字或 12 个英文字符，混合输入折算；我的、设置和排名提交使用共同的常用屏蔽词规则，命中时不保存昵称。内置词表是基础规则，可继续维护扩充。
头像、班级和积分都保存在本机；清理浏览器数据会清除它们。
积分商城目前仅展示“敬请期待”插画，尚未开放 PK 道具兑换、跨设备积分或真实 PK 对战。
首页底部“关于我们”展示制作人 Yvonne Zhao、Ajuna Jiang，以及首席测试官陆泓钰。

## 素材加载

预览页面内嵌小狮子与两张图标图集，配合 WebP 减少体积，避免单独素材请求失败时空白。邀请海报复用同一插画。
完整服务仍提供 WebP / PNG 回退；素材加载失败会提示重试。更新后若微信仍显示旧页面，可重新打开带版本号的入口 `https://jwj-dot12.github.io/Game/?v=ui12`。

## 微信真机验收

- 引导可完成、可跳过，刷新后存档可读取。
- 三种模式显示不同内容，无横向溢出；配对、喝彩、暂停和恢复正常。
- 通关弹窗显示本关榜，顶部榜默认综合挑战，总分列居中。
- 二维码进入相同单元，复制失败有手动回退，关闭邀请后返回成绩单。
- 分别在 iOS 和 Android 微信验证文件导入、音频、图片长按和外链可达性。
- 自动浏览器测试不能替代微信真机。GitHub Pages 域名的访问质量以目标网络实测为准。

## 正式联网托管

完整服务使用同源 `/api/public/*`，需要 Node.js 24 与持久 SQLite。
部署到支持持久磁盘的服务器/容器平台，配置 HTTPS、备份和旧成绩迁移。

若改用腾讯云 CloudBase，不能直接把 SQLite 放到没有持久磁盘的云函数中；需适配云数据库或采用持久存储。
免费套餐按账号控制台为准，不默认创建付费资源。
默认域名主要面向开发测试；正式网页访问需自定义域名。参考 [CloudBase 域名说明](https://docs.cloudbase.net/service/introduce) 与 [套餐说明](https://cloudbase.cloud.tencent.com/pricing)。

## 真正上架微信小程序/小游戏

当前 HTML、DOM、浏览器存储和音频不能直接作为原生小游戏代码上传。后续需要：

1. 在 [微信公众平台](https://mp.weixin.qq.com/) 配置本人/本机构应用，按后台要求选择合适类型、类目并取得 AppID。游戏玩法需确认小游戏接入要求。
2. 用微信开发者工具建立项目。复用词表、计分规则、插画和音频，适配渲染、存储、音频、网络、分享及文件导入。
3. 配置合法请求域名或云环境，服务端关联真实用户身份并继续校验成绩；AppSecret 不得放入前端或 GitHub。
4. 在开发者工具调试，用管理员预览入口进行真机验证。
5. 补齐后台当前要求的主体、类目、隐私和相关材料；资格、认证或审核费用以微信后台为准，不保证原生上架完全免费。
6. 上传代码版本，在后台提交审核，通过后再发布。

官方入口：[微信开发文档](https://developers.weixin.qq.com/)、[小程序文档](https://developers.weixin.qq.com/miniprogram/dev/framework/)、[小游戏文档](https://developers.weixin.qq.com/minigame/dev/guide/)。
原生版本的适配、真机验收和审核提交尚未完成。
